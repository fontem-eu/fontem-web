N1: Hierarchical Navigation

N1 Replace flat tab bar with grouped navigation

Problem

The current DataViewSelector lists 9 views in a flat horizontal row: Profile, Summary, Fundamentals, Income, Cash Flow, Balance, Valuation, Contracts, GMR Long. On mobile, this overflows. As we add more views (Graph Explorer, Directors, Group), it becomes unusable.

Proposed structure

Overview
  ├── Profile          (company card + directors + contracts summary + group)
  └── Graph Explorer   (interactive entity graph — N2)

Financials
  ├── Summary          (price chart + key stats)
  ├── Fundamentals     (ratio table)
  ├── Income           (income statement)
  ├── Cash Flow        (cash flow statement)
  ├── Balance          (balance sheet)
  └── Valuation        (EV multiples)

Procurement
  └── Contracts        (sortable table with TED links)

Analysis
  └── GMR Long         (value investing screen)

UX design

  • Desktop (>768px): Two-level navigation. Top row: category pills (Overview, Financials, Procurement, Analysis). Below: sub-views for the active category. Clicking a category selects its first sub-view.
  • Mobile (<768px): Single dropdown selector that shows Category › View (e.g., “Financials › Income”). Tappable, compact, no overflow.
  • URL structure unchanged: /c/:ticker/:view — the view key is still flat (e.g., income, contracts). The hierarchy is purely a UI concept.

N2: Interactive Graph Explorer

N2 Entity relationship graph with filtering, depth control, and locking

Concept

A visual graph showing all relationships an entity has with other entities. The user can explore the knowledge graph interactively: adjust depth, filter by entity type, lock important nodes, and click through to any entity’s profile.

Technology: Cytoscape.js

Cytoscape.js is purpose-built for interactive graph visualization. It supports force-directed and hierarchical layouts, node/edge filtering, node pinning (locking), event handling, and has a small bundle (~170 KB gzipped, no dependencies).

API endpoint

GET /api/graph/{entity_id}?depth=1&types=Company,Contract,Person,Authority

Response:

UI controls

ControlBehavior
Depth slider (0–3)0 = center only. 1 = direct. 2 = two hops. 3 = three hops. Re-fetches API.
Type filters (checkboxes)Company, Contract, Authority, Person, CPV. Toggle visibility client-side.
Keyword filter (text)Matches against node labels. Client-side, instant.
Lock node (right-click or toggle)Locked nodes stay visible regardless of filters. Pinned in layout. Lock icon indicator.
Click nodeTooltip with entity details + “Go to profile” link.

Node & edge styling

Nodes:
  Company    → circle, blue,   size proportional to contract count
  Contract   → diamond, amber, size proportional to value_eur
  Authority  → hexagon, green
  Person     → triangle, purple
  CPV        → small dot, grey

Edges:
  AWARDED_TO    → solid arrow
  AWARDED       → solid arrow
  SUBSIDIARY_OF → dashed arrow
  DIRECTS       → dotted arrow
  LISTED_AS     → thin grey (hidden by default)
  REPORTED      → thin grey (hidden by default)

Performance

Node explosion at depth >2.

Siemens at depth 2 could yield thousands of nodes. Mitigations:

  • API caps at 500 nodes. Returns truncated: true.
  • Type filter applied server-side (Cypher WHERE) to reduce data.
  • Depth 3 is opt-in (not slider default).
  • REPORTED and LISTED_AS edges hidden by default.

Component structure

src/components/
  GraphExplorer.vue        — Cytoscape canvas + layout management
  GraphControls.vue        — depth slider, type checkboxes, keyword input
  GraphNodeTooltip.vue     — entity detail panel on click

src/api/
  graph.js                 — fetchGraph(entityId, depth, types)
